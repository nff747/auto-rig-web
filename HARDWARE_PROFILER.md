# Dynamic Hardware Profiling & Adaptive Execution

### Client GPU Capability Tiers
- Dynamically probed adapter vendor, limits, and compute throughput upon initialization.
- Selected execution profile (High-Performance, Balanced, or Low-Power) adaptively.

### Thermal Throttling Mitigation
- Monitored sustained frame dispatch deltas and adjusted simulation resolution on frame drops.
- Guaranteed 60 FPS baseline even under elevated system thermal constraints.
