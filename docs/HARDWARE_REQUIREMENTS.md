# Hardware & Platform Matrix // Auto Rig Web

## Recommended Production Targets
- **Graphics Pipeline:** WebGPU-compliant browser (Chrome 128+, Edge 128+, Safari 18+ on macOS Sonoma/Sequoia).
- **Compute Fallback:** Multi-threaded Web Workers with `SharedArrayBuffer` support.
- **CPU Architecture:** x86_64 with AVX2 or ARM64 (Apple Silicon M-series, Graviton).

## Minimum Operating Specifications
- Memory: 512 MB available system RAM.
- GPU: Dedicated or unified GPU with at least 128 MB VRAM allocated to browser context.
